# Rank and EXP implementation plan

**Goal:** Square the home cards; retain assignment/exam EXP; show position-based ranks, 25 demo students and automatic rank announcements.

**Architecture:** Reuse the immutable point ledger and grading integration. Determine tiers from sorted positions (ties use user ID). Persist system announcements in the existing home feed within the same transaction as point awards. Seed through an explicit, repeatable command.

**Stack:** Spring Boot/JPA/H2, Next.js/React/Tailwind.

- [x] Test boundaries 1/2/3/4–5/6–10/11+, displacement announcements, repeated grading, repeatable demo seed.
- [x] Update RankService and system announcement permissions; support season changes.
- [x] Add explicit 25-student seed with distinct EXP, preserving existing records on rerun.
- [x] Copy supplied rank images; display badges and matching colors; square home cards and ranking frames.
- [x] Run backend tests and frontend checks; seed the local database and verify the rendered UI.

EXP remains score/max × 100 × rankWeight per best result, per active season. Demo EXP is explicitly labeled in the ledger. Announcements concern global ranks; course filters show ranks within their own scope. Existing manual announcements remain supported.
